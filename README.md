# Travel & Booking Dashboard

A complete React-based Travel & Booking Management Dashboard.

## Features

- Dashboard overview
- Destination management
- Trip management
- Customer management
- Booking management
- Payment management
- Calendar
- Analytics
- Search and filtering
- Sorting
- Pagination
- Form validation
- CRUD operations
- Confirmation modals
- Toast notifications
- Responsive design
- Charts and analytics
- 404 page handling

## Technologies

- React
- Vite
- React Router
- Lucide React
- Recharts
- CSS
